# Bazar-e-Pak

A Pakistani business discovery and digital marketplace platform — helping local businesses build an online presence and connect with customers.

## ✨ Features

- Browse businesses, shops, and products
- Clean, responsive, mobile-friendly UI
- Reusable, component-based frontend architecture
- Fast, modern user experience

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **Tailwind CSS**
- **DaisyUI**
- **React Icons**
- **React Hot Toast**
- **Swiper**
- **Next/Image**

## 🎨 Design

| Element              | Color     |
| -------------------- | --------- |
| Primary (Dark Green) | `#001B08` |
| Accent (Gold)        | `#E8BB44` |
| Background           | `#F7F5EF` |

## 🚀 Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd bazar-e-pak

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
